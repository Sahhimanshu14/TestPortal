## 💻 4. Interactive CBT Online Exam Simulator (Web App)

A complete offline-ready web application built with modern web technologies:

### How to Access:
- **Direct in Browser:** Simply open [`index.html`](index.html) in Google Chrome, Microsoft Edge, or Firefox.
- **Local Server:** The local web server is currently running at:
  ```
  http://localhost:8080/index.html
  ```
  (Or start at any time using: `python -m http.server 8080`)

### Key Features:
1. **Full-Length Mock Mode**:
   - **Paper 1 (English)**: 120 Questions, 100 Marks, 120 Minutes live countdown.
   - **Paper 2 (GS)**: Complete real test with detailed constitutional & historical explanations.
   - **Paper 3 (Math)**: 100 Questions, 100 Marks, 120 Minutes live countdown.
2. **Chapter-Wise Test Series**:
   - Practice by topic across **14 English chapters**, **6 GS subjects**, and **13 Mathematics chapters**.
3. **Official UPSC Exam Interface**:
   - Real-time countdown timer with pause/resume and low-time alert.
   - Question Palette with 5 authentic UPSC states:
     - 🟩 **Green**: Answered
     - 🟥 **Red**: Not Answered
     - ⬜ **Gray**: Not Visited
     - 🟪 **Purple**: Marked for Review
     - 🟣 **Purple + Green**: Answered & Marked for Review
   - Navigation: *Save & Next*, *Clear Response*, *Mark for Review & Next*, *Previous*.
   - Question Paper Overview modal & Instructions viewer.
4. **Automated UPSC Evaluation & Analytics**:
   - Computes marks using official UPSC negative scoring (+0.833 / -0.277, +1.0 / -0.333).
   - Verifies **mandatory 20% sectional qualifying cutoff** (20.00 marks).
   - Generates merit classifications (*Top 1% Exceptional for IMA/AFA, Strong Competitive, Average, Disqualified*).
   - Solution review mode with filters (*All, Correct, Incorrect, Unattempted*) and full rationale.

## 📊 5. Official UPSC CDS Scoring Standard

$$\text{Final Score} = (\text{Correct Answers} \times M) - (\text{Incorrect Answers} \times P)$$

- **English & GS:** $M = +0.833$, $P = 0.277$
- **Mathematics:** $M = +1.000$, $P = 0.333$
- **Unattempted Questions:** $0$ marks
- **Mandatory Sectional Cutoff:** Minimum **20.00 Marks (20%)** in each paper to qualify for IMA, INA, AFA, and OTA.
